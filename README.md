# FIX FF

Небольшой фанатский PWA-компаньон для Free Fire MAX: ручные профили чувствительности, список подготовки к матчу и таймер тренировки. Настройки хранятся в браузере на устройстве.

Сайт не входит в аккаунт, не подключается к Free Fire MAX и не управляет игрой. Профиль iPhone 13 — только стартовая точка для ручной проверки в самой игре; он не гарантирует попадания. Меняй по одному параметру и проверяй его в тренировочной зоне.

## Публикация через GitHub Pages

1. Создай **публичный** репозиторий GitHub и загрузи в него все файлы и папку `.github/workflows`.
2. Открой **Settings → Pages** и выбери **GitHub Actions** как источник публикации.
3. После завершения действия **Deploy static site to GitHub Pages** сайт появится по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.
4. На iPhone открой опубликованный HTTPS-адрес в Safari и нажми **Поделиться → На экран Домой**.

Публичный репозиторий делает исходный код видимым всем. Не добавляй в него пароли, токены или другие секреты.
