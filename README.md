# FIX FF

Небольшой фанатский PWA-компаньон для Free Fire MAX: поиск по каталогу популярных телефонов с добавлением своей модели, ручные профили чувствительности (включая пробный профиль «Контроль отдачи»), список подготовки к матчу и часовой таймер самостоятельной тренировки. Таймер запускается нажатием, его можно поставить на паузу; он не управляет игрой. Настройки хранятся в браузере на устройстве.

Каталог не может включать все существующие модели телефонов. Профили не откалиброваны для отдельных устройств: чувствительность зависит от игры, обновлений и личных предпочтений. Сайт не входит в аккаунт, не подключается к Free Fire MAX и не управляет игрой. Меняй по одному параметру и проверяй его вручную в тренировочной зоне.

## Публикация через GitHub Pages

1. Создай **публичный** репозиторий GitHub и загрузи в него все файлы и папку `.github/workflows`.
2. Открой **Settings → Pages** и выбери **GitHub Actions** как источник публикации.
3. После завершения действия **Deploy static site to GitHub Pages** сайт появится по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.
4. Открой опубликованный HTTPS-адрес на устройстве. В зависимости от браузера и платформы сайт можно установить через меню браузера или использовать прямо в браузере.

Публичный репозиторий делает исходный код видимым всем. Не добавляй в него пароли, токены или другие секреты.
